# PsycheAI - AI-Powered Emotional Counseling Platform

A full-stack emotional counseling web application with AI-powered analysis and privacy-first architecture.

## Tech Stack

### Frontend
- React + Vite
- Tailwind CSS
- Framer Motion
- Deployed on Vercel

### Backend
- Node.js + Express
- PostgreSQL (Supabase)
- Deployed on Render

### AI Service
- Python FastAPI
- Emotional analysis engine
- Deployed on Railway

## Project Structure

```
psycheai/
├── frontend/          # React + Vite application
├── backend/           # Node.js Express API
├── ai-service/        # Python FastAPI service
└── docs/              # Documentation
```
