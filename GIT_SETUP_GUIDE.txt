========================================
  STEP-BY-STEP: PUSH TO GITHUB
========================================

STEP 1: Add all files to Git
-----------------------------
Command: git add .
Explanation: Stages all files (respecting .gitignore rules)

STEP 2: Create first commit
----------------------------
Command: git commit -m "Initial commit: PsycheAI full-stack application"
Explanation: Saves the staged files to Git history

STEP 3: Create GitHub repository
---------------------------------
1. Go to: https://github.com/new
2. Repository name: PsycheAI (or your choice)
3. Description: AI-powered emotional counseling web application
4. Choose: Private (recommended for projects with sensitive data)
5. DO NOT initialize with README (we already have one)
6. Click "Create repository"

STEP 4: Connect to GitHub
--------------------------
Command: git remote add origin https://github.com/YOUR_USERNAME/PsycheAI.git
Explanation: Links your local repo to GitHub
(Replace YOUR_USERNAME with your actual GitHub username)

STEP 5: Rename branch to main (if needed)
------------------------------------------
Command: git branch -M main
Explanation: Renames default branch to 'main'

STEP 6: Push to GitHub
-----------------------
Command: git push -u origin main
Explanation: Uploads your code to GitHub
(-u sets upstream for future pushes)

========================================
  TROUBLESHOOTING
========================================

If you accidentally committed .env files:
-----------------------------------------
git rm --cached backend/.env frontend/.env
git commit -m "Remove .env files from tracking"
git push

If you need to update .gitignore:
----------------------------------
1. Edit .gitignore
2. git rm -r --cached .
3. git add .
4. git commit -m "Update .gitignore"
5. git push
